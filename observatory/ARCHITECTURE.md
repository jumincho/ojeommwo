# 관측소 v2.6 구조

`app/`은 3D 코스모스·취향 지도/목록·검색·상세 보기의 React UI다. WebGL은 지연 로드하고 비가시 탭에서는 멈춘다. 장식 오브젝트는 메뉴 클릭을 가로채지 않으며 WebGL 정리와 reduced-motion을 지원한다. 좁은 화면의 카테고리 이름은 투영 위치 충돌을 피하고 앞쪽 레이블을 먼저 보여준다.

`worker/`는 Sites Worker다. `SNAPSHOTS` R2에 게시된 검증 스냅샷을 읽으며 공개 화면에는 정제된 집계만 제공한다. 게시 경로는 보호 토큰, 크기·시각·스키마·해시 검증을 거쳐 새 객체를 승격한다. `scripts/export-snapshot.mjs`는 상위 7개 운영 저장소를 읽어 카테고리, 선호, 배달 근거의 공개 표현과 재료 태그를 생성한다. 새 메뉴도 같은 변환 경로를 통과한다.

호스트의 `scripts/refresh-snapshot-host.sh`는 컨테이너 DB 검증 → 임시 스냅샷 생성·검증 → 원자 승격 → Sites 전송 → 공개 API 해시 대조 순서로 동작한다. 10분 게시와 5분 오프셋 health가 설정돼 있다. Sites가 응답하더라도 pororo가 꺼지면 새 DB 내용은 게시되지 않는다. 사용 중인 브라우저는 자동 새로고침하지 않는다.

`out/`은 로컬 비상 뷰어를 위한 서버 빌드 산출물이다. 서버의 관측소 소스를 먼저 변경·검증하고 Sites 게시 및 Windows 비상 사본으로 동기화한다. `runtime`은 프로젝트 밖의 보호 상태로 연결되며 배포·정리 시 건드리지 않는다.
