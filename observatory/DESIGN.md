# 관측소 v2.6 디자인 기준

기존 우주 시각화와 어두운 색조, 모든 사용자 문구·용어·정보량을 유지한다. 첫 화면에서 코스모스/취향 지도 전환, 검색/필터 진입과 메뉴 둘러보기 카드가 곧바로 사용 가능해야 한다. 시각 장식은 데이터 별과 클릭을 가리지 않는다.

취향 지도는 비선호 0% · 중립 50% · 선호 100%를 텍스트, 색, 기호, 표면 패턴으로 함께 구별한다. 인접점도 각각 선택할 수 있도록 24px 이상 조작 영역과 가까운 점 대리 선택을 유지한다. 선호도 퍼센트는 숨기지 않는다. 이전에 제거한 내부 계산 메타데이터나 자동 화면 갱신을 다시 노출하지 않는다.

모바일 하단 탐색은 제목과 '다시 뽑기'를 같은 행에 두고 카드를 아래에서 가로로 탐색한다. 버튼 문구가 세로로 꺾이거나 카드 위에 겹치면 회귀다. 3D 카테고리 이름은 화면 공간 충돌을 피하고 선택/전면 항목을 우선한다. 기본 조작 글꼴은 가능한 한 14px 이상, 보조 정보는 12px 이상, 포인터 목표는 최소 24px을 유지한다. 200% 글자 확대·짧은 화면·키보드·reduced-motion·WebGL 부재도 확인한다.

참고 기준: [WCAG 2.2](https://www.w3.org/TR/wcag/)의 대비·목표 크기·텍스트 확대 원칙. UI 변경은 서버에서 구현하고 실제 브라우저에서 좁은 화면과 데스크톱을 확인한다.
