# 관측소 v2.6 보안 경계

공개 사이트는 검증·정제한 스냅샷만 제공한다. 원본 Slack 식별자, 자유 입력 원문, OAuth/Slack/공공 API 키, 원본 DB를 포함하지 않는다. R2 게시 경로는 토큰 인증, 요청 크기·시각·스키마·SHA-256 검사 후 원자적으로 승격한다. 사이트의 CSP는 실제 HTML 빌드와 동적 import/WebGL 작동까지 브라우저에서 확인한다. 데이터 텍스트는 HTML 코드로 실행하지 않는다.

의존성은 pnpm lock과 보안 patch를 유지한다. 배포 전 `corepack pnpm audit --prod`, 악성 이미지 입력 회귀, lint·typecheck·빌드를 다시 실행한다. `/root` 0710, 프로젝트 0750, 관측소 소유권/권한, 운영 data 0700, 비밀 파일 0600을 유지한다. 호스트 cron의 실제 계정으로 게시·health를 실행해 Permission Denied 회귀를 확인한다.

사이트 링크에 비밀이나 내부 경로를 넣지 않는다. 기존 Sites 소유권·공개 범위를 보존하고 임시 터널이나 구 8788 포트를 운영 경로로 되돌리지 않는다. 상위 `QUALITY_REPORT.md`의 실행 결과가 현재 검증 범위다.
